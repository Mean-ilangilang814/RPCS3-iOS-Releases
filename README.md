Before playing any games, you need to install the PS3 system firmware:
1. Download the official PS3 firmware file named `UPDATE.PUP`
2. This file is not included with the app – you'll need to obtain it separately
3. Open RPCS3 and select the firmware installation option
4. Choose your `UPDATE.PUP` file when prompted

### Playing Your Games
1. Once firmware is installed, you can add your game files
2. RPCS3 supports multiple game formats: `.pkg`, `.iso`, `.zip`, and unpacked folders
3. Select "Install Game" in the app and browse to your game files
